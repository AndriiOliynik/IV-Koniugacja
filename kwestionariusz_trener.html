Інтерактивний тренажер для вивчення польської офіційної лексики та заповнення персональних анкет.

1. Dane podstawowe (Основні дані)
Правило: Спочатку пишеться ім'я (або два імені), а потім прізвище. Усі власні назви пишуться з великої літери.
Приклад: Jan, Anna Maria, Kowalski, Nowak-Wiśniewska.
Правило: Дівоче (родове) прізвище до шлюбу. Якщо воно не змінювалося або ви чоловік і не змінювали прізвище, можна вказати поточне прізвище або написати brak / takie samo.
Правило: Вказується дата (у форматі ДД.ММ.РРРР або прописом) та місто/країна народження.
Приклад: 12.04.1990 r., Kraków / 15 maja 1998, Kijów.
Правило: Громадянство. У польській мові пишеться з малої літери як прикметник середнього роду (bo to obywatelstwo).
Приклад: polskie, ukraińskie, niemieckie.
Правило: Національність. Пишеться з малої літери як прикметник жіночого роду (bo ta narodowość).
Приклад: polska, ukraińska.
2. Adres i kontakt (Адреса та контакти)
Правило: Адреса постійного проживання. Використовуйте скорочення: ul. (ulica), al. (aleja), m. / lok. (mieszkanie / lokal). Обов'язковий поштовий індекс (XX-XXX).
Правило: Адреса для листування. Якщо збігається з постійною, пишуть: taki sam jak wyżej, j.w. (jak wyżej) або повторюють адресу.
Правило: Номер телефону (бажано з кодом країни, наприклад +48) та коректний e-mail.
3. Wykształcenie i praca (Освіта та робота)
Правило: Рівень освіти (прикметник середнього роду):
• wyższe — вища
• średnie — середня
• zawodowe — професійна
• podstawowe — базова/початкова
Правило:
• Zawód wyuczony — спеціальність за дипломом або здобутою освітою.
• Zawód wykonywany — фактична професія або посада за місцем роботи.

Приклади популярних професій (фінанси, менеджмент, HR):
• Спеціаліст з кадрів / HR: specjalista ds. kadr i płac / specjalista ds. HR (для жінок: specjalistka ds. kadr)
• Рекрутер: rekruter (ч) / rekruterka (ж) або specjalista ds. rekrutacji
• Пошуковець талантів: specjalista ds. pozyskiwania talentów / Talent Acquisition Specialist
• Економіст: ekonomista (ч) / ekonomistka (ж)
• Менеджер: menedżer / manager / kierownik (ч) / kierowniczka (ж)
• Бухгалтер: księgowy (ч) / księgowa (ж) / główny księgowy
• Фінансовий контролер: kontroler finansowy (ч) / kontrolerka finansowa (ж)
• Фінансовий аналітик: analityk finansowy (ч) / analityczka finansowa (ж)
Правило: Назва закладу вищої освіти (Uczelnia), факультету (Wydział) та напряму підготовки (Kierunek).

Приклади для економічних та HR-напрямків:
• Szkoła Główna Handlowa w Warszawie / Wydział Zarządzania / Zarządzanie Zasobami Ludzkimi (ZZL)
• Uniwersytet Ekonomiczny w Krakowie / Wydział Zarządzania / Finanse i Rachunkowość
• Uniwersytet Warszawski / Wydział Nauk Ekonomicznych / Analityka Gospodarcza
4. Dodatkowe informacje (Додаткова інформація)
Правило: Вказується мова та рівень володіння. Можна використовувати шкалу CEFR (A1–C2) або описові терміни польською мовою:

Рівні за шкалою CEFR:
• A1 / A2 — podstawowy (початковий / елементарний)
• B1 / B2 — średnio zaawansowany (середній / вище середнього)
• C1 / C2 — zaawansowany / biegły (просунутий / вільний)
• Ojczysty / Natywny — język ojczysty / native speaker (рідна мова)

Приклади запису:
• język angielski – C1 (biegły), język niemiecki – B1 (średnio zaawansowany)
• angielski (zaawansowany), polski (biegły), ukraiński (ojczysty)
Правило: Сімейний стан залежить від статі:
• Жінки: panna (незаміжня), zamężna (заміжня), rozwiedziona (розлучена), wdowa (вдова).
• Чоловіки: kawaler (неодружений), żonaty (одружений), rozwiedziony (розлучений), wdowiec (удовець).
